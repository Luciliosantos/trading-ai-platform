# Segurança

- Nunca versionar `.env`.
- Nunca armazenar token Telegram no código.
- Criptografar API keys em produção.
- Preferir chaves sem saque.
- Separar dados por cliente.
- Registrar ações administrativas.
- Manter kill switch.
- Real trading deve ser opt-in.
- AI não possui acesso direto ao executor.
- Usar HTTPS em produção.
